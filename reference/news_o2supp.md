# Calculate NEWS score for Oxygen Supplementation (O2 supp)

Calculate NEWS score for Oxygen Supplementation (O2 supp)

## Usage

``` r
news_o2supp(o2supp)
```

## Arguments

- o2supp:

  Logical value indicating if oxygen supplementation is provided
  (TRUE/FALSE)

## Value

Numeric NEWS score for O2 supplementation
