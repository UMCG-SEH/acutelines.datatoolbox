# SOFA liver

This function calculates the liver part of the SOFA score. Platelet
count need to be provided in umol L^-1.

## Usage

``` r
sofa_liver(bili)
```

## Arguments

- bili:

  Bilirubin (umol L^-1)

## Value

partial sofa score
