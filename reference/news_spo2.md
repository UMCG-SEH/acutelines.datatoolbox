# Calculate NEWS score for Oxygen Saturation (SpO2)

Calculate NEWS score for Oxygen Saturation (SpO2)

## Usage

``` r
news_spo2(spo2)
```

## Arguments

- spo2:

  Numeric value representing Oxygen Saturation (%)

## Value

Numeric NEWS score for SpO2
