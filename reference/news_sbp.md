# Calculate NEWS score for Systolic Blood Pressure (SBP)

Calculate NEWS score for Systolic Blood Pressure (SBP)

## Usage

``` r
news_sbp(sbp)
```

## Arguments

- sbp:

  Numeric value representing Systolic Blood Pressure (mmHg)

## Value

Numeric NEWS score for SBP
