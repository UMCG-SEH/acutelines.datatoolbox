# Calculate NEWS score for Respiratory Frequency (RF)

Calculate NEWS score for Respiratory Frequency (RF)

## Usage

``` r
news_rf(rf)
```

## Arguments

- rf:

  Numeric value representing Respiratory Frequency (breaths per minute)

## Value

Numeric NEWS score for RF
